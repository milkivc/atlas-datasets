## 📱 **COMO USAR NO IPAD/CELULAR (PASSO A PASSO)**

### **Método 1: Usando o Arquivo HTML (RECOMENDADO)**

1. **Baixe o arquivo:**
   - `ATLAS_CONSOLE_WEB.html`

2. **Abra no navegador:**
   - Safari (iPad/iPhone)
   - Chrome (Android)

3. **Salve como App:**
   
   **No iPad/iPhone:**
   ```
   1. Abra o arquivo no Safari
   2. Toque no ícone de compartilhar (□ com ↑)
   3. Role para baixo
   4. Toque em "Adicionar à Tela Inicial"
   5. Dê o nome: ATLAS CONSOLE
   6. Toque em "Adicionar"
   ```
   
   **No Android:**
   ```
   1. Abra o arquivo no Chrome
   2. Toque nos 3 pontos (⋮)
   3. Toque em "Adicionar à tela inicial"
   4. Dê o nome: ATLAS CONSOLE
   5. Toque em "Adicionar"
   ```

4. **Use o app:**
   - Toque no ícone **ATLAS CONSOLE** na tela inicial
   - O menu aparecerá com 8 botões grandes
   - Toque no botão da função desejada
   - Todas as informações serão exibidas
   - Toque em "Voltar" para retornar

### **Método 2: Usando Termux (Android)**

1. **Instale o Termux** (Google Play ou F-Droid)
2. **Execute:**
   ```bash
   pkg update && pkg upgrade
   pkg install git python curl
   git clone https://github.com/milkivc/atlas-datasets.git
   cd atlas-datasets
   chmod +x ATLAS_CONSOLE_QUICK.sh
   ./ATLAS_CONSOLE_QUICK.sh
   ```
